📚 세특 탭 사용 설명서
STEP 01 / 06
➕
과목 추가하기
왼쪽 상단 과목명 입력란에 과목명을 입력하고 + 추가 버튼을 클릭하세요.
예) 체육, 수학, 국어, 영어
💡 과목은 여러 개 추가할 수 있어요. 탭으로 전환하며 관리해요!
STEP 02 / 06
🎯
성취기준 입력하기
+ 성취기준 추가 버튼으로 성취기준을 하나씩 입력하세요.
여러 개 입력 가능하며 AI가 문구 작성 시 참고해요.
💡 성취기준이 구체적일수록 더 좋은 문구가 나와요!
STEP 03 / 06
📋
활동 목록 등록하기
+ 활동 추가 버튼으로 활동명과 설명을 입력하세요.
활동설명은 선택사항이지만 입력하면 AI가 더 정확한 문구를 만들어줘요.
💡 활동명이 나중에 문구 앞에 붙으니 짧고 명확하게 써주세요!
STEP 04 / 06
🤖
AI 문구 받기
📋 AI용 텍스트 복사 버튼을 클릭한 뒤,
ChatGPT나 Claude 같은 AI 채팅창에 붙여넣으세요.
AI가 활동별·등급별 문구를 20개씩 만들어줘요.

활동이 여러 개라면 프롬프트 마지막에 아래 문구를 추가해서 활동별로 나눠서 요청하세요:
"위 활동 중 [활동명] 활동만 먼저 작성해줘"
💡 활동 4개 기준 총 320문장이 생성돼요. 나눠서 받으면 AI가 잘리지 않아요!
STEP 05 / 06
📝
문구 뱅크에 저장하기
AI가 만들어준 문구를 문구 뱅크 텍스트창에 붙여넣고
✨ 형식 정리 버튼을 클릭하세요.
자동으로 [활동명-A] 문장 형식으로 정리돼요.
💡 형식 정리 후 전체 삭제 버튼으로 다시 시작할 수도 있어요!
STEP 06 / 06
✨
학생별 조합하기
오른쪽 패널에서 반을 선택하면 학생 목록이 나타나요.
각 학생의 등급(A/B/C/D)을 설정한 뒤
✨ 조합하기 버튼을 클릭하면 자동으로 문구가 완성돼요!
💡 결과는 수정·복사·CSV 내보내기가 모두 가능해요!

STEP 03 / 03
✏️
개별 수정 및 반 관리
각 학생의 학번·성별은 직접 수정 가능해요.
상단 + 반 추가 버튼으로 여러 반을 만들 수 있어요.
💡 설정 탭에서 JSON 백업을 해두면 데이터를 안전하게 보관할 수 있어요!
✉️ 가정통신문 사용 설명서
STEP 01 / 05
📋
구글 설문지 배포
학생들에게 구글 설문지를 배포해 응답을 수집하세요.
설문 문항 안내 버튼을 눌러 문항 순서를 확인하세요.
첫 번째 문항에 반드시 학번+이름을 입력받도록 해주세요.
💡 구글 설문지 → 응답 탭 → 스프레드시트 연결을 미리 설정해두세요!
STEP 02 / 05
📂

왼쪽 업로드 버튼을 클릭해 파일을 올려주세요.
💡 학생 정보는 선생님 브라우저에만 저장돼요. 개인정보 걱정 없어요!
STEP 03 / 05
🤖
AI용 텍스트 복사
오른쪽 패널에서 10명씩 묶음 복사 버튼을 클릭하거나
왼쪽에서 학생별 개별 AI 텍스트 복사를 클릭하세요.
복사한 내용을 AI 채팅창에 붙여넣으면 돼요.
💡 10명씩 나눠서 요청하면 AI가 중간에 잘리지 않아요!
STEP 04 / 05

AI 결과 붙여넣기

받은 결과를 오른쪽 붙여넣기 창에 넣고 적용하기를 클릭하세요.
💡 ###학번이름 형식이 있어야 학생별로 자동 분리돼요!
